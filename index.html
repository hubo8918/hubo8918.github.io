calsync

A self-hosted tool that mirrors one Apple iCloud calendar into a Google Calendar — strictly one-way.

Privacy Policy Terms of Service Source code

What it does

calsync reads events from a single Apple iCloud calendar over CalDAV and writes a mirror of them into a Google Calendar you own. iCloud is the source of truth; the Google calendar is a read-only reflection of it. You run calsync yourself — on your own machine, server, or container — using your own Google OAuth client credentials.

One-way by design

  • The CalDAV client only issues read operations. There is no code path that writes to iCloud.
  • Attendees and organizers are never copied to Google, so Google never emails invitations or RSVPs on your behalf.
  • Google-side writes only ever touch events that calsync itself created, tracked in a local state file and tagged with a private marker.
  • A run that would delete most of the mirror at once is refused unless you explicitly confirm it.

How it works

  • Incremental. Each run stores a CalDAV sync token, so subsequent runs ask iCloud only for what changed.
  • Recurring events. RRULE / RDATE / EXDATE rules pass through to Google natively instead of being flattened into copies.
  • Timezone-aware. IANA timezones map 1:1; floating times use a configured default timezone.
  • Self-healing. If the sync token expires or local state is lost, calsync falls back to a full reconcile and only pushes real differences.

Google Calendar access

calsync requests the https://www.googleapis.com/auth/calendar scope. It needs this scope because it both manages events in the destination calendar and reads and, when missing, subscribes to that calendar's entry in your calendar list in order to verify the calendar exists and that you have write access to it before any sync begins.

Authorization happens directly between you and Google. The resulting OAuth token is stored on the machine where you run calsync and is never transmitted anywhere else. See the Privacy Policy for details, including how to revoke access.

Running it

git clone https://github.com/hubo8918/calsync.git
cd calsync
cp .env.example .env   # fill in your iCloud and Google settings
docker compose up

Full setup instructions are in the project README.
